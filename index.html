Mod Overview & Version History (v1.0 – v5.0)

SKYFALL is a comprehensive tactical warfare modification built for Minecraft 1.20.1 Forge. Every system from the initial v1.0 release through the v5.0 Master Edition is integrated into a high-performance codebase:

Section 02

Quick-Start Build & Installation Tutorial

Follow these simple steps to install and run SKYFALL on your Minecraft client or server. No complex gradle setup required for players—just download the .jar, put it in your Minecraft mods folder, and launch Forge 1.20.1!

1 Compile the `.jar` (Developers / Source Build)

Extract the mod source archive, open PowerShell or Terminal in the root folder, and execute the Gradle build command:

.\gradlew.bat build

Note: gradlew automatically detects Java and uses cached portable JDK 17 if needed so you never encounter class version errors.

2 Standard Player Installation

Simply download the compiled skyfall-1.0.0.jar file and place it directly into your .minecraft/mods folder, then launch Forge 1.20.1.

Requires Minecraft 1.20.1 with Forge 47.2.0+ and Java 17 installed.

Category 8: Studio Audio System & 4-Way Random Explosions

Engineered in 44.1 kHz 16-bit Mono Ogg Vorbis:

4-Way Randomized Impact Explosions

Every explosion (skyfall:explosion_generic, skyfall:explosion_distant) randomly selects one of 4 uploaded explosion sound files (explosion_blast1..4.ogg) layered with deep seismic sub-bass rumble (explosion_rumble.ogg) and randomized pitch (0.88x – 1.12x) so no two explosions ever sound identical. Overlapping gunfire and reloads never clip.

Category 9: How to Disable Settings Tutorial (Griefing, Fire, Fog, Shake)

You can customize or disable any destructive or visual feature in two ways:

Method A: In-Game GUI Screen (Press K)

Open the SKYFALL Tactical Configuration Screen to toggle block damage, fire spread, camera shake (0%–100%), fog, presets, and audio instantly.

Method B: Server/World Config File (config/skyfall-common.toml)

enableBlockDestruction = true  # Set to false for Zero-Griefing Mode
enableFireSpread = true        # Set to false to stop fire placement
enableFlyingDebris = true      # Set to false to disable FallingBlock debris
enableScorchedCraters = true   # Set to false to stop Blackstone/Magma rims
enableKillstreakRewards = true # Set to false to disable automatic killstreaks
explosionRadiusMultiplier = 1.0# Scales blast size (0.1 to 5.0)
explosionDamageMultiplier = 1.0# Scales entity damage dealt

Category 10: Admin Commands & Hardware Performance Presets

Use these commands in chat or command blocks (requires OP permission level 2): 

# Summon any airstrike directly at coordinates:
/skyfall strike <PRECISION|CARPET|NAPALM|CLUSTER|BUNKER_BUSTER|ORBITAL_LASER|EMP|TACTICAL_NUKE> <x> <y> <z>

# Switch client particle/shader preset:
/skyfall preset <LOW|MEDIUM|HIGH|ULTRA>

# Toggle block damage or fire spread live without restarting:
/skyfall config blockDamage false
/skyfall config fireSpread false

# Emergency lag clear — removes all active missiles, jets, drones, beams:
/skyfall clear_active

# View live diagnostics:
/skyfall status
